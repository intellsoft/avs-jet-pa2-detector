## 🧩 نحوهٔ سفارشی‌سازی

### ۱. افزودن یا تغییر نواحی تعاملی

در SVG، هر بخش قابل کلیک با کلاس `jp2-hotspot` و ویژگی `data-part` مشخص می‌شود:

```html
<g class="jp2-hotspot" data-part="myPart" tabindex="0" role="button">
  <!-- شکل SVG -->
  <rect class="jp2-hl" x="..." y="..." width="..." height="..." />
</g>
```

### ۲. تعریف محتوای هر بخش

در جاوااسکریپت، آبجکت `PARTS` را ویرایش کنید:

```js
var PARTS = {
  myPart: {
    tag: 'تنظیم',
    title: 'عنوان بخش',
    short: 'توضیح کوتاه برای Tooltip',
    body: '<p>توضیحات کامل...</p>',
    options: [
      { label: 'گزینه ۱', name: 'نام گزینه', desc: 'توضیح گزینه' },
      // ...
    ]
  }
};
```

### ۳. مدیریت وضعیت

وضعیت اولیهٔ جامپرها و کلیدها در آبجکت `state` تعریف می‌شود:

```js
var state = {
  myPart: 0,   // ایندکس گزینهٔ انتخاب‌شده
  // ...
};
```

و تابع `applyState()` محل قرارگیری جامپرها را در SVG به‌روزرسانی می‌کند.
